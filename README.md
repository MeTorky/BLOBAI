# BLOBAI - بلوباي 🌐
The first AI-native parallel world.

## What is BLOBAI?
BLOBAI is a full Universe of cute 3D blob characters, each representing a feeling from our daily life. Built entirely with AI in 4K.

Characters: ZAHQAN, NA'SAN, SHAQYAN, FALLAS, MAZAG, LOKLOK, KASLAN, GOO'AN, ALA'AN, RAWWASH + 90 more coming.

## Structure
/characters - Each character has its own folder with 4K image + profile.json + bio.txt
/assets - Logos
/social - Ready to use social bios
